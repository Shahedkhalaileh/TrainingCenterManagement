# TrainingCenterManagement

A C# Console Application for managing a training center.

## Project Overview

This project aims to build a training center management system using C# and Object-Oriented Programming.

## Planned Features

- Student Management
- Instructor Management
- Course Management
- Enrollment Management
- Waiting List
- Payment Management
- Reports
- Activity History

## Technologies

- C#
- .NET
- Git
- GitHub

## Project Status

Currently under development.
